7- Tell me about a challenge or difficult problem you faced. How did you solve it?
+ In my UIT Chat project, I was responsible for the backend, including real-time messaging using WebSocket. One difficult problem I faced was handling message delivery when the user's network connection was unstable. Messages could be missed when the client was temporarily disconnected. I investigated the problem by testing different network conditions and checking the WebSocket connection flow. I realized that WebSocket itself does not store messages when the client is disconnected, so I persisted messages in the database and added a reconnect mechanism. After reconnecting, the client could fetch the messages it had missed. As a result, the messaging system became more reliable, and users could recover messages after a temporary disconnection.
